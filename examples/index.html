A CSS library that looks like a BIOS screen

VGA blue and cyan, square corners, 2px borders and hard drop shadows. Plain CSS and native elements, with no framework required.

Get started Browse components v0.1

Features

Hard shadows

Buttons sink toward their shadow when hovered and pressed, with scrolling halftone dots.

Native elements

Dialogs, selects, checkboxes and progress bars are styled in place, so keyboard and screen readers keep working.

Themeable

Every color, border width and shadow is a --dq-* custom property, with a dark mode behind data-theme="dark".

Install

Link the stylesheet, then use the dq- classes:

<link rel="stylesheet" href="dqcss.min.css">
<button class="dq-btn dq-btn--primary">Click</button>

Press Tab to move between controls and Esc to close a dialog.
